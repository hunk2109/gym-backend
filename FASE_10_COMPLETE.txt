COMPONENTES CREADOS:

1. ResponseFilterService (/src/modules/auth/services/response-filter.service.ts)
   ├─ Filtra datos sensibles según el rol del usuario
   ├─ Métodos:
   │  ├─ filterUserData() - Oculta contraseñas y datos no autorizados
   │  ├─ filterFinancialData() - Oculta notas internas de pagos/ventas
   │  ├─ filterMemberData() - CLIENTE solo ve sus propios datos
   │  ├─ filterProductData() - CLIENTE/ENTRENADOR no ven costo
   │  ├─ filterClassData() - Filtra información de clases por rol
   │  ├─ filterEquipmentData() - Oculta costo a ENTRENADOR
   │  └─ filterResponse() - Método genérico que rutea al filtro correcto
   └─ Tipos soportados: 'user' | 'financial' | 'member' | 'product' | 'class' | 'equipment'

2. ResponseFilterInterceptor (/src/modules/auth/interceptors/response-filter.interceptor.ts)
   ├─ Interceptor global que se aplica a TODAS las respuestas
   ├─ Detecta automáticamente el tipo de datos según la ruta
   ├─ Verifica autenticación del usuario
   ├─ Mapeos de ruta:
   │  ├─ /user-roles, /users → 'user'
   │  ├─ /payments, /sales → 'financial'
   │  ├─ /members → 'member'
   │  ├─ /products → 'product'
   │  ├─ /classes, /enrollments → 'class'
   │  └─ /equipment → 'equipment'
   └─ Previene exposición accidental de datos sensibles
