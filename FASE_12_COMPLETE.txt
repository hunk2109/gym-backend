FLUJO DE CADA TEST:

1. beforeAll():
   ├─ Inicializa NestApp con AppModule
   ├─ Crea usuarios de prueba para cada rol
   │  ├─ ADMIN, ENCARGADO, CAJERO, ENTRENADOR, CLIENTE
   │  └─ Todos con password hasheado
   └─ Realiza login y obtiene JWT token para cada rol

2. Cada test:
   ├─ Realiza una solicitud HTTP a un endpoint específico
   ├─ Adjunta JWT token en header Authorization: Bearer {token}
   ├─ Valida response status code esperado
   │  ├─ 200 OK si autorizado
   │  ├─ 403 FORBIDDEN si no autorizado
   │  └─ 401 UNAUTHORIZED si sin token
   └─ Para filtering tests: valida que datos sensibles NO aparecen

3. afterAll():
   └─ Limpia usuarios de prueba de la base de datos
